# 阶段6：库存预警与统计分析

## 一、阶段目标

实现库存的实时监控与预警、库存盘点功能、经营概况仪表盘及多维度统计报表，为管理决策提供数据支持。

**预计工期：2天**

**前置条件：** 阶段5完成，进货和销售业务流程已就绪，库存数据已有积累。

---

## 二、功能需求

### 2.1 库存实时查看
- 所有角色均可查看当前库存列表
- 库存列表支持按产品名称、分类筛选
- 显示产品名称、分类、规格、单位、当前库存量、安全库存阈值
- 库存低于安全阈值的产品高亮显示

### 2.2 库存预警
- 系统实时计算各农资产品库存量
- 当库存低于安全阈值时，在首页以醒目方式提醒
- 预警列表显示：产品名称、当前库存、安全库存、差额
- 预警可按分类筛选
- 首页展示预警数量统计

### 2.3 库存盘点
- 仓库管理员可进行库存盘点
- 录入实际盘点数量
- 系统自动计算差异（盈亏）
- 确认盘点后更新库存
- 记录盘点日志（变动类型：ADJUST）

### 2.4 报损管理
- 仓库管理员可录入报损记录
- 记录报损产品、数量、原因
- 报损后自动扣减库存
- 记录库存变动日志（变动类型：DAMAGE）

### 2.5 经营概况仪表盘
- 首页展示关键经营指标：
  - 今日/本月/本年销售额
  - 今日/本月/本年进货额
  - 当前库存产品总数
  - 库存预警产品数量
  - 本月新增客户数
  - 本月进货单数/销售单数
- 销售趋势图（近30天销售折线图）
- 产品分类销售占比（饼图）
- 库存预警产品列表

### 2.6 统计报表
- **销售报表：** 按日/月/年统计销售额、销售量，支持导出
- **进货报表：** 按日/月/年统计进货额、进货量，按分类统计占比
- **库存报表：** 各产品当前库存、库存价值（按进价计算）
- **利润报表：** 销售额 - 进货成本 = 毛利润（简化计算）
- **客户报表：** 客户购买金额排行

### 5.4 核心业务逻辑

**库存盘点流程：**
1. 查询当前系统库存：`currentStock`
2. 获取实际盘点数量：`actualStock`
3. 计算差异：`difference = actualStock - currentStock`
4. 更新库存：`currentStock = actualStock`
5. 记录库存变动日志（变动类型：ADJUST，变动数量为差异值）

**报损处理流程：**
1. 校验产品库存是否充足：`currentStock >= quantity`
2. 扣减库存：`currentStock -= quantity`
3. 记录库存变动日志（变动类型：DAMAGE）

**经营概况数据获取流程：**
1. 查询今日/本月/本年销售额和销售单数
2. 查询本月进货额和进货单数
3. 查询库存产品总数和预警数量
4. 查询本月新增客户数
5. 组装返回 DashboardOverviewVO

**销售趋势数据获取流程：**
1. 查询近30天每天的销售额和订单数
2. 用0填充没有数据的日期
3. 组装日期列表和数据列表

**库存预警SQL：**
```sql
SELECT p.id, p.name, p.safety_stock, i.current_stock,
       (i.current_stock - p.safety_stock) AS difference
FROM product p
JOIN inventory i ON p.id = i.product_id
WHERE p.safety_stock > 0
  AND i.current_stock < p.safety_stock
  AND p.status = 1
ORDER BY difference ASC;
```

## 六、MyBatis XML 关键SQL

### 6.1 库存列表查询（含预警判断）

```xml
<select id="selectInventoryList" resultType="InventoryVO">
    SELECT p.id AS product_id,
           p.name AS product_name,
           p.category_id,
           c.name AS category_name,
           p.specification,
           u.name AS unit_name,
           IFNULL(i.current_stock, 0) AS current_stock,
           p.safety_stock,
           IFNULL(i.frozen_stock, 0) AS frozen_stock,
           CASE WHEN p.safety_stock > 0 AND IFNULL(i.current_stock, 0) < p.safety_stock 
                THEN true ELSE false END AS is_warning,
           (IFNULL(i.current_stock, 0) - p.safety_stock) AS difference,
           (IFNULL(i.current_stock, 0) * p.purchase_price) AS stock_value
    FROM product p
    LEFT JOIN product_category c ON p.category_id = c.id
    LEFT JOIN unit u ON p.unit_id = u.id
    LEFT JOIN inventory i ON p.id = i.product_id
    WHERE p.status = 1
    <if test="productName != null and productName != ''">
        AND p.name LIKE CONCAT('%', #{productName}, '%')
    </if>
    <if test="categoryId != null">
        AND p.category_id = #{categoryId}
    </if>
    <if test="warningOnly != null and warningOnly == 1">
        AND p.safety_stock > 0 AND IFNULL(i.current_stock, 0) < p.safety_stock
    </if>
    ORDER BY is_warning DESC, p.category_id, p.id
</select>
```

### 6.2 经营概况 - 销售统计

```xml
<!-- 今日销售额 -->
<select id="selectTodaySales" resultType="map">
    SELECT IFNULL(SUM(total_amount), 0) AS amount, COUNT(*) AS count
    FROM sales_order
    WHERE status != 2 AND order_date = CURDATE()
</select>

<!-- 本月销售额 -->
<select id="selectMonthSales" resultType="map">
    SELECT IFNULL(SUM(total_amount), 0) AS amount, COUNT(*) AS count
    FROM sales_order
    WHERE status != 2 
      AND YEAR(order_date) = YEAR(CURDATE())
      AND MONTH(order_date) = MONTH(CURDATE())
</select>
```

### 6.3 近30天销售趋势

```xml
<select id="selectSalesTrend" resultType="SalesStatItem">
    SELECT DATE_FORMAT(order_date, '%m-%d') AS date,
           IFNULL(SUM(total_amount), 0) AS amount,
           COUNT(*) AS count
    FROM sales_order
    WHERE status != 2
      AND order_date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
    GROUP BY order_date
    ORDER BY order_date
</select>
```

### 6.4 分类销售占比

```xml
<select id="selectCategorySales" resultType="CategorySalesVO">
    SELECT pc.name AS category_name,
           SUM(soi.subtotal) AS amount,
           SUM(soi.quantity) AS quantity
    FROM sales_order_item soi
    JOIN sales_order so ON soi.order_id = so.id
    JOIN product p ON soi.product_id = p.id
    JOIN product_category pc ON p.category_id = pc.id
    WHERE so.status != 2
      AND so.order_date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
    GROUP BY pc.id, pc.name
    ORDER BY amount DESC
</select>
```

## 九、注意事项

1. 库存盘点和报损操作必须使用 `@Transactional` 注解保证数据一致性。
2. 库存盘点是直接将系统库存设为实际数量，而非增量调整。
3. 利润报表为简化计算（销售额 - 进货成本），未考虑退货、报损等影响。
4. 经营概况接口涉及多个聚合查询，建议优化SQL性能或考虑缓存。
5. 近30天销售趋势需用0填充无数据的日期，避免图表出现断点。
6. 库存报表中的库存价值使用参考进价计算，实际进价可能有差异。
7. 统计查询涉及大量数据时注意性能，建议添加适当的数据库索引。
