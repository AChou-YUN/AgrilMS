# 阶段0：项目环境搭建与基础配置

## 一、阶段目标

完成项目的依赖配置、数据源连接、项目分层结构搭建和通用组件封装，为后续业务开发奠定基础。

**预计工期：1天**

---

## 二、任务清单

### 2.1 补全 Maven 依赖

在 `pom.xml` 中添加以下依赖：

| 依赖 | groupId | 说明 |
|------|---------|------|
| MyBatis Starter | `org.mybatis.spring.boot:mybatis-spring-boot-starter` | MyBatis 集成 |
| MySQL 驱动 | `com.mysql:mysql-connector-j` | MySQL 连接驱动 |
| Lombok | `org.projectlombok:lombok` | 简化实体类代码 |
| JWT | `io.jsonwebtoken:jjwt-api` + `jjwt-impl` + `jjwt-jackson` | Token 认证 |
| Swagger/Knife4j | `com.github.xiaoymin:knife4j-openapi3-jakarta-spring-boot-starter` | API 文档 |
| Hutool（可选） | `cn.hutool:hutool-all` | 工具类库 |
| Validation | `org.springframework.boot:spring-boot-starter-validation` | 参数校验 |

**注意：** 当前 pom.xml 使用的是 Spring Boot 4.0.6（Jakarta EE），需确认各依赖版本兼容性。部分 starter 名称可能与 Spring Boot 3.x 略有不同，需根据实际情况调整。

### 2.2 配置数据源

修改 `application.properties`（或改用 `application.yml`）：

```yaml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/agricultural_ims?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: 123456
    driver-class-name: com.mysql.cj.jdbc.Driver

mybatis:
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: org.example.demo222.entity
  configuration:
    map-underscore-to-camel-case: true
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
```

### 2.3 创建项目分层目录结构

在 `src/main/java/org/example/demo222/` 下创建以下包：

```
├── config/           # 配置类
├── controller/       # 控制器层
├── service/          # 业务逻辑层
│   └── impl/         # 服务实现
├── mapper/           # Mapper 接口
├── entity/           # 实体类
├── dto/              # 数据传输对象
│   ├── request/      # 请求DTO
│   └── response/     # 响应DTO
├── common/           # 通用组件
├── interceptor/      # 拦截器
├── exception/        # 异常处理
└── util/             # 工具类
```

在 `src/main/resources/` 下创建：
```
├── mapper/           # MyBatis XML 映射文件
```

### 2.4 统一响应封装

创建 `common/Result.java`：

```java
@Data
public class Result<T> {
    private int code;       // 状态码：200成功，其他为错误
    private String message; // 提示信息
    private T data;         // 数据

    public static <T> Result<T> success(T data) { ... }
    public static <T> Result<T> success(String message, T data) { ... }
    public static <T> Result<T> error(String message) { ... }
    public static <T> Result<T> error(int code, String message) { ... }
}
```

创建 `common/PageResult.java`：

```java
@Data
public class PageResult<T> {
    private long total;     // 总记录数
    private long pageNum;   // 当前页码
    private long pageSize;  // 每页大小
    private List<T> list;   // 数据列表
}
```

### 2.5 全局异常处理

创建 `exception/BusinessException.java`：

```java
public class BusinessException extends RuntimeException {
    private int code;
    public BusinessException(String message) { ... }
    public BusinessException(int code, String message) { ... }
}
```

创建 `exception/GlobalExceptionHandler.java`：

```java
@RestControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(BusinessException.class)
    public Result<?> handleBusinessException(BusinessException e) { ... }
    
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> handleValidationException(MethodArgumentNotValidException e) { ... }
    
    @ExceptionHandler(Exception.class)
    public Result<?> handleException(Exception e) { ... }
}
```

### 2.6 跨域配置

创建 `config/CorsConfig.java`：

```java
@Configuration
public class CorsConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/**")
                .allowedOriginPatterns("*")
                .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                .allowedHeaders("*")
                .allowCredentials(true)
                .maxAge(3600);
    }
}
```

### 2.7 MyBatis 配置类（可选）

创建 `config/MyBatisConfig.java`，配置分页插件等。

## 三、验证标准

| 验证项 | 验证方法 |

## 五、注意事项

1. Spring Boot 4.0.6 使用 Jakarta EE 命名空间（`jakarta.*`），注意排除使用 `javax.*` 的旧依赖。
2. MySQL 驱动推荐使用 `com.mysql:mysql-connector-j`，而非旧版 `mysql:mysql-connector-java`。
3. MyBatis Starter 版本需兼容 Spring Boot 4.x，建议使用 `3.0.x` 以上版本。
4. 项目编译通过后方可进入下一阶段。
