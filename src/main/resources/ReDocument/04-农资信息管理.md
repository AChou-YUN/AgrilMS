# 阶段3：农资信息管理

## 一、阶段目标

实现农资产品的全生命周期管理，包括农资分类管理、计量单位管理、农资产品的增删改查、模糊搜索及安全库存阈值设置等功能。

**预计工期：2天**

**前置条件：** 阶段2完成，用户认证与权限系统已就绪。

---

## 二、功能需求

### 2.1 农资分类管理
- 系统管理员可增删改查农资分类（种子、化肥、农药、农膜等）
- 支持分类排序
- 删除分类前检查是否有关联产品

### 2.2 计量单位管理
- 系统管理员可管理计量单位（千克、袋、瓶等）
- 单位名称唯一性校验

### 2.3 农资产品管理
- 管理员或经销商可添加、编辑、删除农资产品
- 产品信息包含：名称、类别、规格、计量单位、安全库存阈值、生产厂家、批号、生产日期、保质期、参考进价、参考售价、描述等
- 产品列表支持按类别筛选、按名称模糊搜索
- 产品状态管理（上架/下架）
- 删除产品前检查是否有关联的进货单或销售单

### 2.4 产品信息展示
- 产品列表分页展示，支持多条件组合搜索
- 产品详情页展示完整信息及当前库存量
- 按分类浏览产品

### 5.4 核心业务逻辑

**新增产品流程：**
1. 校验产品名称是否重复（可选）
2. 插入产品记录
3. 创建对应的库存记录（inventory表，初始库存为0）

**删除产品流程：**
1. 检查是否有关联的进货单明细
2. 检查是否有关联的销售单明细
3. 检查当前库存是否为0
4. 删除产品记录及对应库存记录

**产品查询流程：**
1. 关联查询产品表、分类表、单位表、库存表
2. 动态SQL拼接查询条件
3. 计算是否低于安全库存阈值
4. 返回分页结果

**MyBatis XML 关键SQL示例：**

```xml
<select id="selectByPage" resultType="ProductVO">
    SELECT p.*, 
           c.name AS category_name, 
           u.name AS unit_name, 
           i.current_stock,
           CASE WHEN i.current_stock < p.safety_stock THEN 1 ELSE 0 END AS low_stock
    FROM product p
    LEFT JOIN product_category c ON p.category_id = c.id
    LEFT JOIN unit u ON p.unit_id = u.id
    LEFT JOIN inventory i ON p.id = i.product_id
    <where>
        <if test="name != null and name != ''">
            AND p.name LIKE CONCAT('%', #{name}, '%')
        </if>
        <if test="categoryId != null">
            AND p.category_id = #{categoryId}
        </if>
        <if test="status != null">
            AND p.status = #{status}
        </if>
        <if test="manufacturer != null and manufacturer != ''">
            AND p.manufacturer LIKE CONCAT('%', #{manufacturer}, '%')
        </if>
        <if test="lowStock != null and lowStock == 1">
            AND i.current_stock < p.safety_stock AND p.safety_stock > 0
        </if>
    </where>
    ORDER BY p.create_time DESC
</select>
```

## 八、注意事项

1. 产品新增时必须同步创建库存记录，避免库存表数据缺失。
2. 模糊搜索使用 `LIKE CONCAT('%', #{name}, '%')`，注意SQL注入防护（MyBatis的`#{}`已自动防护）。
3. 删除产品前必须检查关联数据，防止数据不一致。
4. 产品列表查询涉及多表关联，建议编写高效的SQL并添加适当索引。
5. 参考进价和参考售价仅作为默认值，实际进货和销售时可修改。
6. 安全库存阈值设为0表示不启用该产品的库存预警。
