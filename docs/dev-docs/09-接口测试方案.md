## 二、接口清单与测试计划

### 基础信息
- **Base URL**: `http://localhost:8080`
- **认证方式**: JWT Bearer Token（Header: `Authorization: Bearer <token>`）
- **管理员测试账号**: admin / admin123（需手动分配 ADMIN 角色）

### 🔥 Swagger UI（推荐测试方式）
项目已集成 **SpringDoc OpenAPI**，可直接在浏览器中进行接口测试：

| 地址 | 说明 |
|------|------|
| `http://localhost:8080/swagger-ui/index.html` | Swagger UI 交互式测试页面 |
| `http://localhost:8080/v3/api-docs` | OpenAPI JSON 描述文档 |

**使用步骤**：
1. 浏览器打开 `http://localhost:8080/swagger-ui/index.html`
2. 先调用 `POST /api/auth/login` 登录获取 Token
3. 点击 Swagger UI 页面右上角 **Authorize** 按钮
4. 输入 `Bearer <your_token>`，点击 Authorize
5. 之后所有接口调用都会自动携带 Token

### 获取 Token 测试命令
```bash
# 注册用户
curl -s -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123","realName":"系统管理员","phone":"13800000001","email":"admin@agri.com"}'

# 登录获取 Token（需先在数据库分配角色）
curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

## 六、已知问题与注意事项

1. **MySQL `only_full_group_by` 模式**: 所有使用 `DATE_FORMAT()` 在 SELECT 中的 GROUP BY 查询必须在 GROUP BY 中也使用相同的 `DATE_FORMAT()` 表达式，不能使用 `YEAR()/MONTH()` 简写。**（已修复）**

2. **注册默认角色**: 注册接口默认分配 RETAILER 角色，admin 用户需手动在数据库中分配 ADMIN 角色才能执行管理员操作。

3. **DevTools 限制**: Spring DevTools 可以自动重启 Java 代码变更，但 MyBatis XML 文件的修改需要手动重启应用才能生效。

4. **Token 有效期**: JWT Token 有效期为 24 小时（86400000ms），过期后需重新登录。
