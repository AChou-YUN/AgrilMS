# 农资进销存管理系统 — 开发总计划

## 一、项目概述

**项目名称：** 基于SSM框架的农资进销存管理系统  
**技术栈：** Spring Boot 4.0.6 + MyBatis + MySQL 8.x + Vue 3 + Element Plus  
**开发语言：** Java 17（后端）、JavaScript/TypeScript（前端）

### 1.1 项目目标

面向农资经销商、零售商、仓库管理员及系统管理员，实现农资（种子、化肥、农药、农膜等）的进货、销售、库存全流程信息化管理，包括采购入库、销售出库、库存预警、客户管理、供应商管理及销售统计等功能。

### 1.2 四种用户角色

| 角色 | 职责 |
|------|------|
| 经销商 | 管理进货与供应商，录入进货订单 |
| 零售商 | 销售开单，管理农户客户信息 |
| 仓库管理员 | 查看库存、处理出入库、库存盘点、报损退货 |
| 系统管理员 | 用户管理、基础数据配置（农资分类、计量单位等） |

## 二、开发阶段总览

| 阶段 | 名称 | 预计工期 | 主要内容 |
|------|------|----------|----------|
| 阶段0 | 项目环境搭建与基础配置 | 1天 | 补全Maven依赖、配置数据源、项目分层结构搭建、统一响应封装 |
| 阶段1 | 数据库设计与MyBatis集成 | 2天 | 设计所有数据库表、编写实体类、Mapper接口、MyBatis映射文件 |
| 阶段2 | 用户与权限管理 | 2天 | 四种角色的登录注册、JWT认证、权限拦截器、用户管理CRUD |
| 阶段3 | 农资信息管理 | 2天 | 农资产品CRUD、分类管理、模糊搜索、安全库存阈值 |
| 阶段4 | 进货与供应商管理 | 2天 | 进货单录入、供应商管理、进货自动增库存、进货历史查询 |
| 阶段5 | 销售与客户管理 | 2天 | 销售开单、客户管理、自动扣减库存、销售单打印模拟、按时间段统计 |
| 阶段6 | 库存预警与统计分析 | 2天 | 库存实时计算、低库存预警、库存盘点、日/月/年报表、图表数据接口 |
| 阶段7 | Vue前端开发与集成 | 3天 | Vue项目搭建、所有页面开发、前后端联调 |

**总预计工期：约16天**

## 三、项目分层架构

```
src/main/java/org/example/demo222/
├── config/           # 配置类（跨域、MyBatis、拦截器等）
├── controller/       # 控制器层（REST API）
├── service/          # 业务逻辑层
│   └── impl/         # 服务实现类
├── mapper/           # MyBatis Mapper接口
├── entity/           # 数据库实体类
├── dto/              # 数据传输对象（请求/响应）
├── common/           # 通用工具（统一响应、枚举、常量等）
├── interceptor/      # 拦截器（权限校验等）
└── exception/        # 全局异常处理
```

前端结构（Vue 3）：
```
frontend/
├── src/
│   ├── api/          # API请求封装
│   ├── views/        # 页面组件
│   ├── components/   # 公共组件
│   ├── router/       # 路由配置
│   ├── store/        # 状态管理（Pinia）
│   ├── utils/        # 工具函数
│   └── assets/       # 静态资源
├── public/
└── package.json
```

## 七、质量要求

1. **代码规范：** 遵循Java编码规范，使用统一的代码风格
2. **接口规范：** RESTful API设计，统一响应格式 `{code, message, data}`
3. **异常处理：** 全局异常处理器，统一错误码
4. **数据校验：** 前后端双重数据校验
5. **安全性：** JWT Token认证，角色权限控制，SQL注入防护
6. **可维护性：** 清晰的分层架构，合理的注释文档
